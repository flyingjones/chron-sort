# Release v0.1.2

## Breaking Changes

- Removed old progress reporting
  - Removed ``--progress-at`` option since an animated progress bar has been added
- Removed old ``--dry-run`` file. Replaced with summary report which can be toggled independently of using a dry run.

## New Features

### Animated Progress Bar
Added animated progress bar. Will report the current progress in 0.1 % intervals

- It can be disabled using ``--progress-bar false``
- The characters using to render the bar can be configured with ``--progress-bar-chars ``
- Estimates time remaining based on ``time passed`` / ``progress`` * (1 - ``progress``)
- Is shown for:
  - The reading of the dates for all files in the source path (The progress is based on processed file count)
  - Moving / copying the files to the destination path (The progress is based on processed file count)

### Updated Reporting

Rebuild reporting of the sorting in the console and changed the way ``--dry-run`` works
- Added Markdown summary tables which are printed to the console and to the summary file for the following:
  - Used configuration
  - File scan summary (number of files found with what file endings in source directory)
  - Sorting summary (number of files for each year and number of conflicts)
  - Write summary (writing results for each year)
- Added the ``--summary-path`` to specify a path where a Markdown summary file should be created. The summary file will contain the following:
  - All summary tables which are also printed to the console
  - A detailed description of each conflict
  - A detailed description for what happened for each file grouped by the result directory path
- Added ``--escape-summary-tables`` to enable / disable escaping in Markdown tables in summary file.

### Updated Dry-Run

Changed the way the ``--dry-run`` option works. Now it does the same thing as no dry-run in most places and only skips writing to the file system.
This enables it to detect conflicts with files already existing in the destination directory and detect conflicts in the source directory.
- The old dry-run file has been removed
- The new ``--summary-path`` option works with dry-run so this can be used to check what exactly will happen.
