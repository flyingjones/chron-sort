# Release v0.1.2

## Breaking Changes

- Removed old progress reporting
  - Removed ``--progress-at`` option

## New Features

- Added animated progress bar. Will report the current progress in 0.1 % intervals
  - It can be disabled using ``--progress-bar false``
  - The characters using to render the bar can be configured with ``--progress-bar-chars ``
  - Estimates time remaining based on ``time passed`` / ``progress`` * (1 - ``progress``) 
- Added log message for duplicates in the source
  - If multiple files in the source directory are mapped to the same file name in the target directory structure, a message is generated

## Bug Fixes

## Improvements

- Changed default value for ``--skip-parser-when-before`` to ``1950-01-01``
